# Umineko no Naku Koro ni — MAO Translations

[Website](https://mao-tls.github.io/umineko/) · [Releases](https://github.com/MAO-TLs/umineko/releases)

An English translation of both the PC and PS3 scripts, a bilingual online reader, and comparative audits of Witch Hunt, Umineko Project, and MangaGamer.

The playable add-on requires a working Umineko Project installation and legally obtained game resources. Installation instructions and release notes are available on the website and in the release archive. No base game is included.

## Website

The static website is in `public/`. Run `npm test` with Node.js 24 to check the reader, audit links, typography, publication manifest, and release metadata. GitHub Actions deploys the tested tree to Pages.
