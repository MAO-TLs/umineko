Installation

How to install the patch

Start with a working Umineko Project installation. The MAO add-on contains both PC and PS3 scripts, using Umineko Project’s PS3 presentation. It does not include the base game.

  1. 01

    Install Umineko Project

    Set up Umineko Project with legally obtained game resources and confirm that it runs before adding the translation. Close the game and back up ons.cfg. If updating MAO, also retain the previous archive or back up its files.

  2. 02

    Add the MAO patch

    Extract the complete MAO ZIP into the game directory containing en.file. Merge the graphics and video folders; do not replace those folders wholesale. Existing Umineko Project language packs remain intact.

  3. 03

    Select the English script

    In ons.cfg, set game-script=mao-pc.file for the PC script or game-script=mao-ps3.file for the PS3 script. Preserve your other settings.

  4. 04

    Choose your edition in game

    Start Umineko Project normally. Use System Settings → Game language to switch between MAO PC and MAO PS3. Close settings, then quit and reopen the game to apply your selection. See the complete installation guide for upgrading and removal.

This is a translation add-on.

It does not include the engine, base game resources, voices, music, or video recordings. Both editions use PS3 presentation; PC-only additions without corresponding recordings remain unvoiced.
